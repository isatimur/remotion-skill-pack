## [0.1.0] - 2026-06-09

### Added

- Initial public release of the remotion-skill-pack workspace.
- `@remotion-skill-pack/core` (0.1.0) — schema, `SKILL.md`, bundled themes.
- `@remotion-skill-pack/render` (0.1.0) — CLI + API: `composition.json` → TSX → `.mp4`.
- `@remotion-skill-pack/mcp-server` (0.1.0) — MCP stdio server exposing 5 tools.
- `@remotion-skill-pack/install` (0.1.0) — adapter installer for Claude Code, Cursor, Copilot, Codex, Gemini CLI.
- `@remotion-skill-pack/create-template` (0.1.0) — theme scaffolder.
- `remotion-skill-pack-render` (0.1.0) — Python CLI wrapper (PyPI).
- Bundled themes: `book-chapter`, `minimal-dark`.
